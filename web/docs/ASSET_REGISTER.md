# Asset Register

_Audit: 2026-11-14 (Phase 00, directive "Complete Gameplay Systems"). Inspected with `node tools/inspect-glb.mjs <file> --json`
(reads only the GLB header + JSON chunk; reports in `tools/out/glb/*.json`, not committed)._

## Rules
- **Originals are never modified.** Optimised runtime copies are generated by a script into a separate folder.
- Coordinates: 1 unit = 1 m, +Y up, game +Z = north. All user models below are already metre-scale.
- Browser budget per model (target): ≤ 300 k triangles, ≤ 150 draw calls, textures ≤ 2048² (WebP), file ≤ 40 MB.

### Outpost scale check (main base)
Interior floor sits at model y = 21.65. Dome ≈ 21 m diameter, ≈ 10 m tall; corridors ≈ 3 m tall; Farm 13.6 × 7.7 × 16.5;
Storage 9 × 8 × 9; Comms 12 × 5 × 15; tower ≈ 28 m; windmill ≈ 30 m; conference table top 1.1 m above floor.
Against the player (eye 1.65 m, radius 0.38 m) these are human-scale → **scale 1.0, no rescale**. Only a vertical offset
(floor → terrain) and a small terrain pad are needed.

Layout already matches the reference plan (user image "MAIN OUTPOST" top view) with north = +Z:
Communications & Shields north (+Z), Exit/airlock south (−Z), **Farm greenhouse at +X, Storage/vehicle bay at −X** (corrected
2026-11-15 from in-game views — the 170 k-tri `LOW_M_blinn6` mesh at +X is the Farm's plants). Seen from above with north up, +X is on
the left, so the Farm is left and Storage right exactly as in the plan. **No rotation needed.** (The game's compass calls +X "east" —
see the mirrored-labels issue in DEVELOPMENT_HANDOFF.)

Placement: dome centre on the established outpost site (−1250, 1150). Terrain under the dome + 4 modules varies 1.2 m,
under the whole 130 × 188 m layout 4 m (mean −49.3 m) → a blended flatten pad of ≈ 1 m is enough.

### Stray / problem content found
- ~20 tiny `monitor_hanging_monitor_*` fragments 19 m below the floor (y ≈ 2.5) — cull during optimisation.
- Two solar-array nodes carry 1.42 M of the 2.71 M triangles (`Sketchfab_model.058` 798 k, `.059` 627 k) — must be simplified or replaced by instanced panels.
- Many named empties (`File cabinet*`, `shelf*`) with no geometry.
- 7 400 meshes ⇒ ~7 400 draw calls unoptimised (browser target ≤ ~300 for the whole frame).

## Optimisation plan (needs dev-only tooling, see DEVELOPMENT_HANDOFF "Blocked")
`tools/optimize-models.mjs` (to be written) using glTF-Transform + meshoptimizer + sharp:
dedup → prune → flatten/join by material → weld → simplify heavy meshes (solar arrays) → textures resized to ≤ 2048 and WebP → meshopt
compression. Output to `public/assets/models/opt/`; originals moved to `assets-src/models/` (outside `public/`, so 900 MB
of source never ships in `dist/`). Runtime uses three's bundled `MeshoptDecoder` (no new runtime dependency).
